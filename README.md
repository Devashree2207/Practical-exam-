C Language Practical Exam Programs

This repository contains simple C language programs prepared for a practical examination.

Programs Included

Porositive & Consonant

Accepts a character from the user.

Uses a switch statement to check vowels.

The current program prints "porositive" for vowels and "consonant" for consonants.

It also checks whether the entered character is an alphabet.

Smallest Element in a 1D Array

Accepts the number of elements and their values.

Finds and displays the smallest element in the array.

Function to Reverse a 3 Digit Number

Accepts a 3-digit number.

Uses a separate reverse() function.

Displays the reversed number.

Checks whether the entered number is a valid 3-digit number.

Square of Array Elements Using Pointer

Accepts array elements.

Uses a pointer to access the array.

Displays the square of every element.

Pattern

Uses nested for loops.

Prints the following pattern:

100
81 81
64 64 64
49 49 49 49
36 36 36 36 36
